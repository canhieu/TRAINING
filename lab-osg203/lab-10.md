# Lab 10

#### **1. Kiểm tra giao diện mạng**

**Lệnh:**

```bash
ip addr
```

**Kết quả mẫu:**

```
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN
    inet 127.0.0.1/8 scope host lo
    inet6 ::1/128 scope host
2: enp0s3: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc fq_codel state UP
    link/ether 08:00:27:3a:5b:6c brd ff:ff:ff:ff:ff:ff
    inet 192.168.56.101/24 brd 192.168.56.255 scope global dynamic enp0s3
    inet6 fe80::a00:27ff:fe3a:5b6c/64 scope link
```

**Trả lời:**

* Giao diện **lo**:
  * IPv4: `127.0.0.1`
  * IPv6 rút gọn: `::1`
  * IPv6 đầy đủ: `0000:0000:0000:0000:0000:0000:0000:0001`
* Giao diện **enp0s3** sử dụng **predictable naming scheme** dạng “onboard Ethernet” (`enpXsY`).
* IPv4: `192.168.56.101/24`
* IPv6: `fe80::a00:27ff:fe3a:5b6c/64`
* IPv4 được gán **động (DHCP)** → thấy từ khóa _dynamic_ trong dòng `scope global dynamic`.
* Thời gian hiệu lực phụ thuộc lease của DHCP server, thường là 24 giờ.
* Địa chỉ MAC: `08:00:27:3a:5b:6c`.

#### **2. Làm việc với NetworkManager**

**Lệnh:**

```bash
nmcli
```

**Kết quả mẫu:**

```
enp0s3: connected to Wired connection 1
        inet4 192.168.56.101/24
        inet6 fe80::a00:27ff:fe3a:5b6c/64
        route4 192.168.56.0/24
        route4 0.0.0.0/0
lo: unmanaged
DNS configuration:
        servers: 192.168.56.1
        domains: localdomain
```

**Trả lời:**

* Tên thiết bị Ethernet: `enp0s3`.
* Có 1 router (gateway) duy nhất, hỗ trợ **IPv4**.
* Thiết bị `lo` là **loopback**, MAC address là toàn số 0 vì nó không kết nối vật lý, không có router.
* DNS server: `192.168.56.1`.
* Domain: `localdomain`.

#### **5. Kiểm tra cấu hình file mạng**

**Lệnh:**

```bash
cd /etc/sysconfig/network-scripts
cat ifcfg-enp0s3
```

**Kết quả mẫu:**

```
TYPE=Ethernet
BOOTPROTO=dhcp
ONBOOT=yes
DEVICE=enp0s3
NAME="Wired connection 1"
```

**Trả lời:**

* TYPE: `Ethernet`
* BOOTPROTO: `dhcp`
* ONBOOT: `yes`

Nếu đặt địa chỉ tĩnh cần thêm:

```
IPADDR=192.168.56.50
NETMASK=255.255.255.0
GATEWAY=192.168.56.1
DNS1=8.8.8.8
```

#### **7. Kiểm tra DNS**

**Lệnh:**

```bash
cat /etc/resolv.conf
```

**Kết quả mẫu:**

```
# Generated by NetworkManager
nameserver 192.168.56.1
```

* Lưu trữ thông tin máy chủ tên miền (DNS).
* Nếu không có DNS, bạn không thể truy cập các trang web bằng tên (chỉ bằng IP).

**Lệnh:**

```bash
nslookup www.nku.edu
```

**Kết quả mẫu:**

```
Server:  192.168.56.1
Address: 192.168.56.1#53
Non-authoritative answer:
Name:    www.nku.edu
Address: 34.192.101.9
```

* Canonical name: `www.nku.edu`
* IP: `34.192.101.9`
* Server: `192.168.56.1`

Sau khi comment toàn bộ `/etc/resolv.conf`:

* `nslookup` bị treo vì không có DNS server.
* Khi thêm IP server vào lệnh (`nslookup www.nku.edu 192.168.56.1`) → hoạt động bình thường.
* Thêm `nameserver 8.8.8.8` → dùng Google DNS → `nslookup` hoạt động trở lại.

***

#### **8. Non-authoritative answer**

* “Non-authoritative answer” nghĩa là phản hồi đến từ **DNS trung gian**, không phải DNS gốc có thẩm quyền (authoritative server).
* Khi truy vấn tên miền của trường đại học, có thể là authoritative (nếu máy chủ gốc), còn Google thì thường non-authoritative.

#### **9. Sử dụng lệnh host**

**Lệnh:**

```bash
host www.google.com -v
```

**Kết quả rút gọn:**

* **ANSWER SECTION:** chứa tên và địa chỉ IP của `www.google.com`.
* **AUTHORITY SECTION:** chứa thông tin máy chủ DNS có thẩm quyền.
* **SOA record:** gồm 5 giá trị:
  1. **Serial number** – số hiệu phiên bản bản ghi.
  2. **Refresh** – chu kỳ máy phụ kiểm tra cập nhật.
  3. **Retry** – khoảng thời gian thử lại nếu thất bại.
  4. **Expire** – thời gian hết hạn dữ liệu cũ.
  5. **Minimum TTL** – thời gian sống tối thiểu của bản ghi.

Ví dụ:

```
Serial: 2025102701
Refresh: 3600
Retry: 1800
Expire: 1209600
Minimum TTL: 86400
```

#### **10. Kiểm tra gateway và router**

**Lệnh:**

```bash
nmcli device show enp0s3
```

→ `IP4.GATEWAY: 192.168.56.1`

**Lệnh:**

```bash
ip route
```

Kết quả:

```
default via 192.168.56.1 dev enp0s3 proto dhcp metric 100
```

* Metric: giá trị độ ưu tiên của route, số nhỏ hơn = ưu tiên cao hơn.

#### **11. Kiểm tra thiết bị lân cận**

**Lệnh:**

```bash
ip neigh
```

**Kết quả:**

```
192.168.56.1 dev enp0s3 lladdr 08:00:27:a5:67:90 STALE
```

* “STALE” nghĩa là thông tin tạm thời, chưa được xác nhận.
* Sau khi khởi động lại NetworkManager → “REACHABLE”.

**Xóa cache:**

```bash
ip route flush 192.168.56.1
```

→ Trạng thái trở lại “STALE”.

#### **12. Tính địa chỉ mạng (CIDR)**

Giả sử địa chỉ IPv4: `192.168.56.101/24`

* `/24` → 24 bit mạng → netmask: `255.255.255.0`
* Dạng nhị phân:\
  `11111111.11111111.11111111.00000000`
*   Địa chỉ mạng:

    ```
    192.168.56.101
    AND 255.255.255.0
    = 192.168.56.0
    ```

→ Network address: **192.168.56.0**
